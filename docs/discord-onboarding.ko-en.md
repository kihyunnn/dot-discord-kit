# Discord onboarding / Discord 온보딩

## Existing server / 기존 서버

The agent inspects safe metadata, generates the official Bot install URL, and waits for your consent. It does not create accounts or read user tokens.

에이전트는 안전한 메타데이터만 조사하고 공식 Bot 설치 URL을 만든 뒤 사용자의 승인을 기다립니다. 계정을 만들거나 사용자 토큰을 읽지 않습니다.

## First-time Discord / 처음 사용하는 경우

You create the Discord account, server, and Developer Portal application. The agent verifies the Bot after installation.

사용자가 Discord 계정, 서버, Developer Portal 애플리케이션을 직접 만들고, 설치 후 에이전트가 Bot ID와 권한을 검증합니다.

## Choice prompt / 선택 질문

1. One channel, persistent threads, or Omonya parent + Dot child threads?
2. Is local Dot/CDP available?
3. Should DevSpace be enabled?
4. Which Discord users may invoke Dot?
5. Are text-only results acceptable for now?
